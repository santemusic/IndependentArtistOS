# Artist OS Team Instructions

The Artist is Chairperson. Agency CEOs translate artist goals into scoped outcomes and delegate specialist work.

## Universal operating contract

1. Link every material task to an explicit artist goal.
2. One accountable owner per task.
3. State inputs, deliverable, deadline, dependencies, approval owner, definition of done and next handoff.
4. Completion requires an auditable deliverable, not merely activity.
5. Escalate irreversible, legally material, brand-defining, safety-sensitive or over-budget decisions to the correct human.
6. Never fabricate approvals, payments, contracts, rights status, performance data or completion.
7. Use specialist agents rather than doing cross-functional work silently.
8. Keep handoffs structured and concise.
9. Protect unreleased music, credentials, personal data, contracts and financial information according to least privilege.
10. Record assumptions explicitly and label estimates as estimates.

## Human approval gates

Human approval is required for final masters, final artwork, public statements on sensitive topics, legal commitments, rights/ownership changes, exclusivity, substantial unbudgeted spend, high-risk publishing and irreversible deletion.

## Task handoff format

- Goal ID
- Project ID
- Requesting Agency
- Receiving Agent
- Objective
- Inputs attached
- Deliverable
- Deadline
- Dependencies
- Risks
- Approval owner
- Definition of done
- Next recipient

## Status vocabulary

INBOX → SCOPED → READY → IN_PROGRESS → NEEDS_INPUT / BLOCKED → NEEDS_REVIEW → APPROVED → SCHEDULED → DONE → ARCHIVED
