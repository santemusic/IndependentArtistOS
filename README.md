# Independent Artist OS × Buzz

A multi-agency operating system for independent artists, designed for Buzz-style human + agent collaboration.

## Operating model

**Artist (human Chairperson) → Artist CEO → Agency CEOs → specialist employees → structured handoffs → human approvals → measurable outcomes.**

The system treats every major artist-business function as an Agency: Executive, Music, Release, Content Factory, Marketing & Growth, PR & Media, Live, Partnerships, CRM, Commerce, Finance, Legal & Rights, Data & Intelligence, Operations/PMO, and Automation & AI.

## Start here

- `AGENTS.md` — agency and agent roster

- `.buzz/workflows/` — Buzz workflow examples

## Core governance

AI agents may research, draft, classify, organize, monitor, prepare, recommend and coordinate. Human approval remains mandatory for legal execution, ownership/rights changes, exclusivity, substantial unbudgeted spend, final masters/artwork, sensitive public communication and destructive actions.

## Recommended activation order

Start with `artist-ceo`, `chief-of-staff`, `ops-ceo`, `release-ceo`, `content-ceo`, `growth-ceo`, and `data-ceo`. Prove one real release end-to-end before activating the full specialist workforce.
